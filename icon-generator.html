Générateur d'icônes PWA

Ce générateur crée les icônes nécessaires pour votre PWA eFootball Red Dimension.

192x192

512x512

Instructions :

  1. Cliquez sur "Télécharger les icônes"
  2. Les fichiers icon-192.png et icon-512.png seront téléchargés
  3. Placez-les dans le dossier principal de votre site
  4. Le PWA sera maintenant installable avec ces icônes
